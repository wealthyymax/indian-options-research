# REA and licensing notes

Upstream: https://github.com/morluto/rea

The upstream README currently states that REA-authored code is MIT licensed. It explicitly notes that third-party materials and external analysis tools retain their own licenses and terms. REA is optional in this project; it is not bundled as a dependency and no REA source has been copied into this project.

This workbench is an independent implementation of general quantitative methods. It does not contain code extracted from paid trading platforms.

Market data rights are separate from software rights. NSE's published option-chain page warns against aggregating/copying/duplicating its website content, and NSE Data's policy states that licensed data usage and redistribution are governed by agreements. Use only sample data or data for which you have appropriate rights.
